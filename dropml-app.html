📋 Como funciona o OAuth2
1 Você clica em "Conectar" — abre uma janela de login do Mercado Livre
2 Você autoriza o app DropMLV na sua conta — o ML gera um code
3 O app troca o code por um access_token e salva no navegador
4 A partir daí todas as chamadas à API do ML usam esse token automaticamente
⚠️ O token expira em 6 horas. O app renova automaticamente usando o Refresh Token. Redirect URI: fredas23.github.io/dropml-redirect
